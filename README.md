# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 放映签核

- 每个划痕或色偏片段必须在「试映前核对」里选定**处理结论**（照原样放映、修复后放映、放映时跳过等）。
- 风险项全部处理后，在底部「放映签核」填入签名人生成签核：签核区固定记录当时的**片序、总时长、每条风险结论**，并给出**核对号、签名人、签核时间**。
- 未签核时仍可继续整理片段；此时导出的清单会注明「无可用签核」，仅供整理参考。
- 签核后再**增删片段、调整顺序、修改时长或处理结论**，原核对号立即标记为已失效，必须重新签核；只有有效签核存在时才能导出带核对号的**正式放映清单**。
- 所有数据保存在浏览器 localStorage，不上传任何服务器。
